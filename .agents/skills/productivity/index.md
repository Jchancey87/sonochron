# Productivity Skills

Agent skills designed to improve productivity and context management for agentic coding.

## Available Skills

- [caveman](caveman/SKILL.md) — Ultra-compressed communication mode. Cuts token usage ~75% by dropping filler, articles, and pleasantries while keeping full technical accuracy.
- [handoff](handoff/SKILL.md) — Summarize the current conversation and workspace state into an optimized HTML handoff file for the next agent to continue work.
